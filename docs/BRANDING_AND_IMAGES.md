## Branding Guidelines

### Color Palette

**Primary Colors:**
- Teal: #0a7ea4
- Blue: #0066cc
- Gradient: Teal to Blue

**Secondary Colors:**
- Light Background: #ffffff
- Dark Background: #151718
- Surface: #f5f5f5

**Accent Colors:**
- Success: #22C55E
- Warning: #F59E0B
- Error: #EF4444

### Typography

**Font Family:** Modern sans-serif (Segoe UI, SF Pro Display, Roboto)

**Font Sizes:**
- Headlines: 28-32px
- Subheadings: 18-24px
- Body: 14-16px
- Captions: 12-14px

### Logo Usage

**Do's:**
- ✓ Use official logo files
- ✓ Maintain aspect ratio
- ✓ Ensure adequate spacing
- ✓ Use on contrasting backgrounds
- ✓ Maintain color integrity

**Don'ts:**
- ✗ Stretch or distort logo
- ✗ Change colors without permission
- ✗ Use low-resolution versions
- ✗ Place on similar-colored backgrounds
- ✗ Rotate or flip logo

### Clear Space

Maintain minimum clear space around logos:
- Minimum: 10% of logo width
- No other elements within clear space
- Consistent spacing on all sides

## Image Integration

### In App Configuration

All image URLs are configured in `app.config.ts`:

```typescript
const env = {
  logoUrl: "/manus-storage/metodo-logo-main_fbbce346.png",
  logoTextUrl: "/manus-storage/metodo-logo-text_9ebebd2c.png",
  bannerUrl: "/manus-storage/metodo-banner_73c4b3eb.png",
  featureTasksUrl: "/manus-storage/metodo-feature-tasks_36440349.png",
  featureAvatarUrl: "/manus-storage/metodo-feature-avatar_e0e366ca.png",
  featureThemesUrl: "/manus-storage/metodo-feature-themes_dd971af3.png",
  featureDeveloperUrl: "/manus-storage/metodo-feature-developer_c34d5fbb.png",
  iconTaskUrl: "/manus-storage/metodo-icon-task_28eae538.png",
  iconAvatarUrl: "/manus-storage/metodo-icon-avatar_ea3735f9.png",
  iconThemesUrl: "/manus-storage/metodo-icon-themes_dc961362.png",
};
```

### In Components

Use image URLs in React components:

```tsx
import { Image } from 'react-native';

export function LogoDisplay() {
  return (
    <Image
      source={{ uri: '/manus-storage/metodo-logo-main_fbbce346.png' }}
      style={{ width: 200, height: 200 }}
    />
  );
}
```

### In Documentation

Reference images with proper markdown syntax:

