## Feature Overview

### Task Management
MeTodo provides advanced task management with:
- Task creation with title, description, and rich notes
- Priority levels (Low, Medium, High)
- Due dates and smart reminders
- Subtasks for complex projects
- Recurring task patterns
- Category/tag organization
- Task filtering and sorting

### Avatar Creator
Customize your profile with:
- Hair style and color options
- Eye shape and color selection
- Accessories (glasses, hats, etc.)
- Multiple skin tone options
- Real-time preview
- Local storage persistence

### 50+ Themes
Pre-installed themes include:
- Default (Light & Dark)
- AMOLED Dark
- Pastel Colors
- Neon
- Ocean
- Sunset
- Forest
- Lavender
- Mint
- Coral
- Cyberpunk
- Minimalist
- And 38+ more...

Plus custom theme creation with:
- Primary, secondary, and background color pickers
- Real-time preview
- Save and reuse custom themes

### Developer Options
30+ tools for developers:
- Layout bounds visualization
- Performance overlay
- Touch target display
- Frame rate monitor
- Memory usage tracking
- Debug console
- Network activity monitor
- Database query inspector
- And 22+ more advanced tools
