# MeTodo - Comprehensive API and Service Guide

## Architecture Overview
MeTodo utilizes an enterprise-grade modular architecture featuring tRPC, Drizzle ORM, Express backend, and React Native frontend.

## Core Services & APIs
1. **Task Management Service:** CRUD operations, recurring tasks, smart reminders, and subtasks.
2. **Backend Sync Service:** Offline-first queue management, conflict resolution, and real-time Socket.io synchronization.
3. **Analytics Service:** Productivity tracking, chart rendering, and performance metrics.
4. **PDF Export Service:** Document generation and sharing using `expo-print`.
5. **Notification Service:** Push notifications, reminders, and background scheduling.
