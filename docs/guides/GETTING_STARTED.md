# MeTodo - Getting Started Guide

## Welcome to MeTodo!

MeTodo is a powerful, offline-first task management app that helps you stay productive. This guide will help you get started with the app.

---

## First Launch

### Initial Setup

When you first launch MeTodo, you'll see:

1. **Welcome Screen** - Introduction to the app
2. **Avatar Creation** - Create your personalized avatar
3. **Theme Selection** - Choose your preferred theme
4. **Home Screen** - Main task management interface

### Creating Your Avatar

Your avatar represents you in the app:

1. Tap the **Avatar** tab
2. Customize your avatar:
   - Hair style and color
   - Eye shape and color
   - Accessories (optional)
   - Skin tone
3. View real-time preview
4. Tap **Save Avatar** when satisfied

### Choosing a Theme

MeTodo includes 50+ themes:

1. Go to **Settings** tab
2. Scroll to **Themes** section
3. Tap any theme to preview
4. Tap again to apply
5. Or create a custom theme with **+ Create Custom Theme**

## Main Features

### Home Screen

The home screen shows:

| Section | Description |
|---------|-------------|
| Statistics | Completed, pending, and overdue task counts |
| Recent Tasks | Your most recent tasks |
| Quick Actions | Create new task button |
| Avatar | Your custom avatar |

### Creating Your First Task

1. Tap **+ Create New Task** on home screen
2. Enter task title (required)
3. Add description (optional)
4. Set priority (Low, Medium, High)
5. Choose category (optional)
6. Set due date (optional)
7. Tap **Create Task**

### Managing Tasks

**View All Tasks:**
1. Tap the **Tasks** tab
2. See all your tasks in one place
3. Filter by category or priority
4. Search for specific tasks

**Complete a Task:**
1. Find the task in the list
2. Tap the checkbox to mark complete
3. Task moves to completed section

**Edit a Task:**
1. Tap on any task
2. Modify details as needed
3. Tap **Save Changes**

**Delete a Task:**
1. Open task detail
2. Tap **Delete** button
3. Confirm deletion

## Task Features

### Task Priority

Set task importance:
- **Low** - Can wait, not urgent
- **Medium** - Normal priority (default)
- **High** - Important, needs attention soon

### Due Dates

Set when tasks should be completed:

1. Open task detail
2. Tap **Due Date**
3. Select date from calendar
4. Set optional reminder

### Subtasks

Break complex tasks into steps:

1. Open task detail
2. Tap **Add Subtask**
3. Enter subtask title
4. Check off subtasks as you complete them
5. Main task shows progress

### Reminders

Get notified about important tasks:

1. Open task detail
2. Tap **Add Reminder**
3. Choose reminder time:
   - 5 minutes before
   - 1 hour before
   - 1 day before
   - Custom time
4. Enable notifications in Settings

### Recurring Tasks

Set tasks to repeat automatically:

1. Open task detail
2. Tap **Make Recurring**
3. Choose pattern:
   - Daily
   - Weekly
   - Monthly
   - Yearly
4. Set end date (optional)

### Rich Notes

Add formatted notes to tasks:

1. Open task detail
2. Tap **Notes** section
3. Format text:
   - **Bold** - Highlight important text
   - *Italic* - Emphasize text
   - Lists - Organize information
4. Notes auto-save

## Data Management

### Backup Your Data

MeTodo stores all data locally on your device. To backup:

1. Go to Settings
2. Tap **Export Data**
3. Choose backup location
4. Data is saved as JSON file

### Restore from Backup

To restore previous data:

1. Go to Settings
2. Tap **Import Data**
3. Select backup file
4. Confirm restore
5. All data is restored

### Clear All Data

To start fresh:

1. Go to Settings
2. Tap **Clear All Data**
3. Confirm action
4. All tasks and settings reset

## Troubleshooting

### Tasks Not Saving

**Solution:**
1. Check device storage space
2. Restart the app
3. Try again

### Notifications Not Working

**Solution:**
1. Check Settings > Notifications enabled
2. Verify system notification permissions
3. Restart app

### Avatar Not Displaying

**Solution:**
1. Go to Avatar tab
2. Verify avatar was saved
3. Refresh home screen
4. Restart app if needed

### App Crashes

**Solution:**
1. Clear app cache in Settings
2. Restart device
3. Reinstall app if needed
