## Privacy Policy

### Overview

MeTodo is committed to protecting your privacy. This privacy policy explains how we collect, use, and protect your data.

### Data Collection

**What We Collect:**
- Task data (title, description, due dates, etc.)
- Avatar customization data
- Theme preferences
- User settings

**What We Don't Collect:**
- Personal information (name, email, phone)
- Location data
- Browsing history
- Device identifiers
- Usage analytics (by default)

### Data Storage

**Local Storage:**
- All data stored on your device
- No data sent to servers
- Accessible only to the app

**Cloud Storage (Optional):**
- Available in future versions (v1.2.0+)
- Only with explicit user consent
- Encrypted before transmission
- User can disable at any time

### Data Usage

**How We Use Your Data:**
- To provide app functionality
- To improve user experience
- To fix bugs and issues
- To provide customer support

**What We Don't Do:**
- Sell your data
- Share with third parties
- Use for advertising
- Track your activity
- Monitor your behavior

---

## Data Protection

### Encryption

**Local Data:**
- Stored in encrypted AsyncStorage
- Device-level encryption
- No unencrypted backups

**Cloud Data (Future):**
- End-to-end encryption
- AES-256 encryption
- Secure key management
- TLS/SSL for transmission

### Access Control

**Who Can Access Your Data:**
- Only you (on your device)
- Cloud provider (encrypted data only)
- Support team (with permission)

**Who Cannot Access Your Data:**
- MeTodo creators (local data)
- Third-party services
- Advertisers
- Governments (without warrant)

### Data Deletion

**Delete Local Data:**
```
Settings > Developer Options > Clear Cache
```

**Delete All Data:**
```
Uninstall app
```

**Delete Cloud Data (Future):**
```
Settings > Account > Delete Account
```

## Security Best Practices

### For Users

**1. Device Security**
- Use strong device password
- Enable biometric lock
- Keep device updated
- Use secure Wi-Fi

**2. App Security**
- Use strong app password (future)
- Enable biometric auth (future)
- Don't share device
- Logout when done

**3. Data Backup**
- Export data regularly
- Store backups securely
- Test restore process
- Keep multiple copies

**4. Privacy Settings**
- Review app permissions
- Disable unnecessary features
- Use privacy mode
- Clear cache regularly

### For Developers

**1. Code Security**
- Use secure libraries
- Validate input
- Escape output
- Avoid hardcoding secrets

**2. API Security**
- Use HTTPS
- Validate requests
- Rate limiting
- Error handling

**3. Data Security**
- Encrypt sensitive data
- Use secure storage
- Implement access control
- Log security events

**4. Testing**
- Security testing
- Penetration testing
- Vulnerability scanning
- Code review
