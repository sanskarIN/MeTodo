## Switching Themes

### Quick Theme Switch

1. Navigate to **Settings** tab
2. Scroll to **Themes** section
3. Tap any theme thumbnail
4. Theme applies immediately
5. Changes persist across sessions

### Theme Preview

Each theme shows:
- Primary color swatch
- Secondary color swatch
- Theme name
- Visual preview

## Custom Theme Creator

### Creating a Custom Theme

1. Go to **Settings** tab
2. Tap **+ Create Custom Theme**
3. Enter a unique theme name
4. Select colors:
   - **Primary Color** - Main accent color
   - **Secondary Color** - Secondary accent
   - **Background Color** - App background
5. Preview updates in real-time
6. Tap **Save Theme**

## Color Theory Tips

### Creating Harmonious Themes

**Complementary Colors:**
- Use colors opposite on the color wheel
- Example: Blue (#0066FF) + Orange (#FF6600)

**Analogous Colors:**
- Use colors adjacent on the color wheel
- Example: Blue (#0066FF) + Purple (#6600FF)

**Triadic Colors:**
- Use three colors evenly spaced
- Example: Red, Yellow, Blue

### Accessibility Considerations

- Ensure sufficient contrast (WCAG AA minimum 4.5:1)
- Avoid pure red/green combinations
- Test with color blindness simulators
- Prioritize readability

### Popular Color Combinations

**Professional:**
- Primary: #0a7ea4 (Teal)
- Secondary: #6366f1 (Indigo)
- Background: #ffffff (White)

**Creative:**
- Primary: #ff6b6b (Red)
- Secondary: #ffa07a (Orange)
- Background: #fff5e1 (Cream)

**Dark Mode:**
- Primary: #00ffff (Cyan)
- Secondary: #ff00ff (Magenta)

## Best Practices

### Creating Effective Themes

1. **Test Readability** - Ensure text is readable
2. **Consider Contrast** - High contrast for accessibility
3. **Limit Colors** - Use 3-5 main colors
4. **Match Mood** - Choose colors that match your workflow
5. **Test on Device** - Preview on actual device

### Using Themes Effectively

1. **Match Time of Day** - Light themes for day, dark for night
2. **Task-Based Themes** - Different themes for different projects
3. **Seasonal Themes** - Update themes seasonally
4. **Accessibility** - Choose high-contrast themes if needed

## Troubleshooting

### Theme Not Applying

- Ensure theme is selected
- Restart the app
- Check device storage
- Try switching to another theme first

### Custom Theme Not Saving

- Verify theme name is entered
- Check device storage space
- Ensure colors are valid hex codes
- Try again with simpler color values

### Colors Look Different on Device

- Display settings may affect appearance
- Adjust device brightness
- Try different theme
- Check color calibration
