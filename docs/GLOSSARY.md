## FILE PURPOSE
This comprehensive glossary defines all terminology, acronyms, and concepts used in MeTodo documentation and development.

---

## A

**API (Application Programming Interface)**
A set of protocols and tools for building software applications. APIs define the methods and data formats that applications can use to communicate with each other.

**AsyncStorage**
A React Native module for storing data asynchronously on the device. Used for persistent local storage of tasks and preferences.

**Avatar**
A personalized visual representation of the user in MeTodo. Can be customized with different hair styles, eye shapes, accessories, and skin tones.

**Authentication**
The process of verifying user identity. MeTodo supports OAuth authentication for secure user login.

---

## B

**Backend**
Server-side code that handles business logic, data storage, and API endpoints. MeTodo backend is built with Node.js and Express.

**Bundle Size**
The total size of all JavaScript code sent to the client. Smaller bundle sizes result in faster app loading.

**Babel**
A JavaScript compiler that transforms modern JavaScript code into compatible versions for older browsers and devices.

---

## C

**Category**
A way to organize tasks by type (e.g., Work, Personal, Health). Each task can belong to one category.

**Context (React Context)**
A React feature for managing global state without prop drilling. MeTodo uses Context for theme and task state management.

**CRUD**
Create, Read, Update, Delete. The four basic operations for managing data.

---

## D

**Dark Mode**
A display mode with dark backgrounds and light text. Reduces eye strain and battery consumption on OLED devices.

**Developer Options**
Advanced debugging and monitoring tools accessible by tapping the app version 10 times. Includes 30+ tools for developers and power users.

**Deep Link**
A URL that directs users to a specific screen within the app (e.g., metodo://task/123).

---

## E

**Expo**
A framework and platform for building React Native apps. Provides tools for development, testing, and deployment.

**ESLint**
A JavaScript linting tool that identifies and reports code quality issues.

---

## F

**FlatList**
A React Native component for rendering large lists efficiently. Preferred over ScrollView for performance.

**Framework**
A collection of pre-built code and tools that provide structure for building applications.

---

## G

**Git**
A version control system for tracking code changes and collaborating with other developers.

**GraphQL**
A query language for APIs that allows clients to request exactly the data they need.

---

## H

**Haptics**
Tactile feedback vibrations that provide physical feedback to user interactions.

**Hook (React Hook)**
A React function that lets you use state and other React features in functional components.

---

## I

**IDE (Integrated Development Environment)**
A software application that provides tools for writing, testing, and debugging code (e.g., VS Code).

---

## J

**JSON (JavaScript Object Notation)**
A lightweight data format for storing and exchanging data. Used for API responses and data storage.

---

## K

**Keystore**
A file containing cryptographic keys used for signing Android apps.

---

## L

**Linting**
Automated code analysis to identify style issues and potential bugs.

**Local Storage**
Data stored on the device rather than on a server. MeTodo uses AsyncStorage for local storage.

---

## M

**Metro**
The JavaScript bundler for React Native apps. Bundles code for development and production.

**Middleware**
Software that sits between the client and server to handle requests and responses.

**Memoization**
A performance optimization technique that caches function results to avoid unnecessary recalculations.

---

## N

**NativeWind**
A library that brings Tailwind CSS to React Native. Used for styling MeTodo components.

**Node.js**
A JavaScript runtime for building server-side applications.

---

## O

**OAuth**
An open standard for authentication and authorization. Used for secure user login.

**Offline-First**
An architecture where the app works offline and syncs data when connection is available.

---

## P

**Package Manager**
A tool for managing project dependencies (e.g., npm, yarn, pnpm).

**Prettier**
A code formatter that automatically formats code to a consistent style.

**Priority**
The importance level of a task (Critical, High, Medium, Low).

---

## Q

**Query**
A request for data from an API or database.

---

## R

**React**
A JavaScript library for building user interfaces with reusable components.

**React Native**
A framework for building native mobile apps using React and JavaScript.

**Recurring Task**
A task that repeats on a schedule (daily, weekly, monthly, yearly).

**Reminder**
A notification to alert the user about an upcoming or overdue task.

---

## S

**SafeArea**
A React Native component that ensures content doesn't overlap with system UI elements (notches, home indicators).

**Schema**
The structure and organization of data in a database.

**State**
Data that changes over time in a React component or application.

**Subtask**
A smaller task that is part of a larger task. Used to break down complex tasks.

**Sync**
The process of synchronizing data between the local device and a server.

---

## T

**Tag**
A label applied to tasks for organization and filtering (e.g., urgent, important).

**Theme**
A set of colors and styles that define the app's appearance. MeTodo includes 50+ themes.

**TypeScript**
A programming language that extends JavaScript with static type checking.

---

## U

**UI (User Interface)**
The visual elements and controls that users interact with.

**UX (User Experience)**
The overall experience and satisfaction of using the app.

---

## V

**Version**
A specific release of the software (e.g., v1.0.0).

---

## W

**Webpack**
A module bundler for JavaScript applications.

---

## X

**XML (eXtensible Markup Language)**
A markup language for storing and transporting data.

---

## Y

**YAML (YAML Ain't Markup Language)**
A human-readable data serialization format used for configuration files.

---

## Z

**Zustand**
A state management library for React (alternative to Redux).
