## Introduction

### What Are Themes?

Themes are pre-designed color schemes that change the appearance of MeTodo. Each theme includes coordinated colors for the entire app interface.

### Why Use Themes?

- **Personalization:** Make app look like yours
- **Mood:** Match your current mood
- **Productivity:** Different themes for different tasks
- **Accessibility:** Choose high-contrast themes
- **Fun:** Enjoy variety and change
- **Brand:** Match your personal brand

### Theme Features

- 50+ pre-installed themes
- Custom theme creator
- Dark mode support
- Theme scheduling
- Easy switching
- Theme management

## Accessing Themes

### Open Settings

**Step 1: Navigate to Settings**

- Current theme name
- Quick theme switcher

- Custom themes list

## Applying Themes

### Quick Theme Switch

**Method 1: From Themes Screen**
1. Go to Settings
2. Tap "Themes"
3. Browse themes
4. Tap theme to select
5. Theme applied immediately

**Method 2: From Quick Settings**
1. Go to Settings
2. Look for "Current Theme" section
3. Tap theme preview
4. Quick theme selector opens
5. Tap theme to apply

### Previewing Themes

**Before Applying:**
1. Tap theme name
2. Preview screen opens
3. See full app with theme
4. Scroll through screens
5. Check colors and appearance

**Live Preview:**
1. Tap "Preview" button
2. App updates with theme
3. Navigate through app
4. See theme in action
5. Confirm before saving

## Dark Mode

### Understanding Dark Mode

**What It Is:**
- Inverted color scheme
- Dark backgrounds
- Light text
- Reduced eye strain
- Evening-friendly

### Enabling Dark Mode

**Automatic Dark Mode:**
1. Go to Settings
2. Tap "Appearance"
3. Toggle "Auto Dark Mode"
4. App switches at sunset
5. Switches back at sunrise

**Manual Dark Mode:**
1. Go to Settings
2. Tap "Appearance"
3. Toggle "Dark Mode"
4. App switches immediately
5. Stays in dark mode

### Dark Mode Themes

**Pre-Installed Dark Themes:**

**Creating Dark Theme:**

- Significant battery savings
- Extended usage time

## Troubleshooting

### Theme Not Applying

**Problem:** Theme won't apply
**Solution:**
1. Restart app
2. Try different theme
3. Clear app cache
4. Reinstall app if needed

### Colors Look Wrong

**Problem:** Colors appear different
**Solution:**
1. Adjust screen brightness
2. Check color picker
3. Try different color
4. Check display settings

### Theme Not Saving

**Problem:** Custom theme won't save
**Solution:**
1. Check theme name
2. Ensure colors selected
3. Try again
4. Contact support

### Theme Scheduling Not Working

**Problem:** Themes not switching automatically
**Solution:**
1. Check scheduling enabled
2. Verify times set correctly
3. Restart app
4. Check device time
