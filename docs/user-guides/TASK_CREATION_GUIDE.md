## Getting Started

### Open Task Creation Screen

To create a new task, follow these steps:

**Step 1: Navigate to Home Screen**
- Open MeTodo app
- Ensure you're on the Home tab (bottom left)

**Step 2: Tap Create Button**
- Look for the blue "+ Create New Task" button at the bottom
- Tap it to open the task creation screen

**Step 3: Task Creation Form Opens**
- You'll see a form with fields for task details
- Start filling in the information

### Understanding the Task Creation Form

The task creation form has several sections:

**Basic Information Section**
- Task Title (required)
- Task Description (optional)
- Category (optional)

**Details Section**
- Priority level
- Due date
- Reminders
- Tags

**Advanced Section**
- Subtasks
- Recurring pattern
- Notes

## Creating Your First Task

### Simple Task (Minimal Information)

For a quick task, you only need the title:

**Step 1: Enter Title**
- Tap the "Task Title" field
- Type your task name (e.g., "Buy groceries")
- Keep it clear and concise

**Step 2: Save Task**
- Tap the blue "Save" button
- Task is created and appears in your task list

**Example Simple Tasks:**
- Buy milk
- Call mom
- Finish report
- Schedule meeting
- Send email

### Complete Task (All Information)

For a detailed task with all information:

**Step 1: Enter Basic Information**
- Title: "Prepare quarterly report"
- Description: "Compile sales data and create presentation"
- Category: "Work"

**Step 2: Set Details**
- Priority: High
- Due Date: June 30, 2026
- Reminders: 1 day before, 1 hour before

**Step 3: Add Subtasks**
- Subtask 1: Collect sales data
- Subtask 2: Analyze trends
- Subtask 3: Create presentation
- Subtask 4: Review and finalize

**Step 4: Set Recurring Pattern**
- Frequency: Monthly
- Repeat on: Last Friday of month

**Step 5: Add Notes**
- "Include comparison with previous quarter"
- "Use template from last year"

**Step 6: Save Task**
- Tap the blue "Save" button
- Task is created with all details

## Task Properties

### Task Title

**What It Is:**
The name of your task. This is the most important property and is required.

**Best Practices:**
- Be specific and clear
- Use action verbs (e.g., "Buy", "Complete", "Call")
- Keep it concise (under 50 characters)
- Avoid vague titles like "Stuff" or "Things"

**Examples:**
- ✅ "Buy groceries for dinner"
- ✅ "Complete project proposal"
- ✅ "Call dentist for appointment"
- ❌ "Stuff"
- ❌ "Things to do"
- ❌ "Work"

### Task Description

**What It Is:**
A longer explanation of the task. This is optional but helpful for complex tasks.

**When to Use:**
- Complex tasks that need explanation
- Tasks with multiple steps
- Tasks that need context
- Tasks you might forget details about

**Best Practices:**
- Be concise but thorough
- Explain the "why" not just the "what"
- Include any important details
- Use clear language

**Example:**
```
Title: "Prepare quarterly report"
Description: "Compile Q2 sales data from all regions, analyze trends, 
create presentation with charts, and prepare summary for board meeting."
```

### Category

**What It Is:**
A way to organize tasks by area of life or work.

**Default Categories:**
- Work
- Personal
- Shopping
- Health
- Finance
- Education
- Other

**How to Use:**
- Assign each task to a category
- Filter tasks by category
- View category statistics
- Organize your life

**Best Practices:**
- Use consistent categories
- Don't create too many categories (5-10 is ideal)
- Use categories that match your life areas
- Review and adjust categories regularly

## Priority Levels

### Understanding Priorities

MeTodo uses four priority levels to help you focus on what matters most:

| Priority | Color | Meaning | When to Use |
|----------|-------|---------|------------|
| Critical | Red | Must do today | Urgent and important |
| High | Orange | Do soon | Important but not urgent |
| Medium | Yellow | Do this week | Somewhat important |
| Low | Green | Do when possible | Nice to have |

### Setting Priority

**During Task Creation:**
1. Tap the "Priority" field
2. Select from: Critical, High, Medium, Low
3. Choose based on importance and urgency

**After Task Creation:**
1. Tap the task to open details
2. Tap "Edit"
3. Change priority
4. Save changes

### Priority Matrix

Use this matrix to determine priority:

```
                Urgent      Not Urgent
Important       CRITICAL    HIGH
Not Important   MEDIUM      LOW
```

**Critical (Urgent + Important):**
- Deadlines today
- Emergency situations
- Time-sensitive tasks
- High-impact tasks

**High (Not Urgent + Important):**
- Important projects
- Long-term goals
- Strategic tasks
- Personal development

**Medium (Urgent + Not Important):**
- Interruptions
- Requests from others
- Administrative tasks
- Routine tasks

**Low (Not Urgent + Not Important):**
- Nice to have
- Someday tasks
- Low-impact tasks
- Leisure activities

### Best Practices for Priorities

- Don't make everything critical
- Review priorities regularly
- Adjust as circumstances change
- Focus on high-priority tasks first
- Reassess when overwhelmed

## Due Dates & Reminders

### Setting Due Dates

**During Task Creation:**
1. Tap "Due Date" field
2. Select date from calendar
3. Optionally set time
4. Save task

**After Task Creation:**
1. Tap task to open
2. Tap "Edit"
3. Change due date
4. Save changes

**Due Date Options:**
- Today
- Tomorrow
- This week
- Next week
- This month
- Next month
- Custom date

### Understanding Due Dates

**Overdue Tasks:**
- Tasks past their due date
- Shown in red
- Appear at top of list
- Need immediate attention

**Due Today:**
- Tasks due today
- Shown in orange
- Appear high in list
- Prioritize these

**Due Soon:**
- Tasks due within 3 days
- Shown in yellow
- Plan to complete soon

**Future Tasks:**
- Tasks due later
- Shown in normal color
- Plan ahead for these

### Setting Reminders

**Reminder Types:**

**Time-based Reminders:**
- At specific time on due date
- 1 hour before
- 1 day before
- 1 week before
- Custom time

**Relative Reminders:**
- When you open app
- When you arrive at location
- When you leave location

**Setting Reminders:**
1. Tap "Reminders" field
2. Choose reminder type
3. Set time/condition
4. Add multiple reminders
5. Save task

**Example Reminders:**
- "1 day before" for important deadlines
- "1 hour before" for meetings
- "When opening app" for daily tasks
- "At 9 AM" for morning routine

### Smart Reminders

Smart reminders learn from your behavior:

**How They Work:**
- Track when you complete tasks
- Learn your patterns
- Suggest optimal reminder times
- Adjust automatically

**Enabling Smart Reminders:**
1. Go to Settings
2. Tap "Smart Reminders"
3. Toggle "Enable"
4. Allow app to learn

## Subtasks

### What Are Subtasks?

Subtasks are smaller tasks within a larger task. They help break down complex tasks into manageable steps.

**Example:**
Main Task: "Plan vacation"
Subtasks:
- Research destinations
- Book flights
- Reserve hotel
- Plan activities
- Pack luggage

### Creating Subtasks

**During Task Creation:**
1. Scroll to "Subtasks" section
2. Tap "+ Add Subtask"
3. Enter subtask title
4. Repeat for each subtask
5. Save main task

**After Task Creation:**
1. Tap task to open
2. Tap "Edit"
3. Scroll to "Subtasks"
4. Tap "+ Add Subtask"
5. Enter subtask title
6. Save changes

### Managing Subtasks

**Completing Subtasks:**
1. Tap task to open details
2. Find subtask in list
3. Tap checkbox to mark complete
4. Subtask is marked done

**Editing Subtasks:**
1. Tap task to open details
2. Tap subtask to edit
3. Change title or details
4. Save changes

**Deleting Subtasks:**
1. Tap task to open details
2. Swipe left on subtask
3. Tap delete button
4. Confirm deletion

### Subtask Progress

**Progress Tracking:**
- App shows completion percentage
- Visual progress bar
- Shows X of Y subtasks complete
- Helps track progress

**Example:**
- 3 of 5 subtasks complete = 60% progress
- Visual bar shows 60% filled
- Motivates completion

## Recurring Tasks

### What Are Recurring Tasks?

Recurring tasks repeat automatically on a schedule. Perfect for tasks you do regularly.

**Examples:**
- Daily: Morning exercise, check emails
- Weekly: Grocery shopping, team meeting
- Monthly: Pay bills, review goals
- Yearly: Birthday gifts, annual review

### Setting Recurring Pattern

**During Task Creation:**
1. Scroll to "Recurring" section
2. Tap "Frequency" dropdown
3. Select: Daily, Weekly, Monthly, Yearly
4. Configure details
5. Save task

**Frequency Options:**

**Daily:**
- Every day
- Every X days
- Weekdays only
- Custom days

**Weekly:**
- Every week
- Every X weeks
- Select specific days
- Example: Monday, Wednesday, Friday

**Monthly:**
- Every month
- On specific date
- On specific day (e.g., last Friday)
- Every X months

**Yearly:**
- Every year
- On specific date
- Every X years

### Managing Recurring Tasks

**Completing Recurring Task:**
1. Tap task to mark complete
2. Task is marked done
3. Next occurrence is created
4. Continues automatically

**Editing Recurring Task:**
1. Tap task to open
2. Tap "Edit"
3. Change details
4. Choose: "This occurrence" or "All occurrences"
5. Save changes

**Stopping Recurring Task:**
1. Tap task to open
2. Tap "Edit"
3. Change frequency to "Never"
4. Save changes

### Recurring Task Examples

**Daily Routine:**
```
Title: "Morning exercise"
Frequency: Daily
Time: 6:00 AM
Reminder: 15 minutes before
```

**Weekly Meeting:**
```
Title: "Team standup"
Frequency: Weekly
Days: Monday, Wednesday, Friday
Time: 10:00 AM
Reminder: 30 minutes before
```

**Monthly Bill:**
```
Title: "Pay electricity bill"
Frequency: Monthly
Date: 1st of month
Reminder: 1 day before
```

**Yearly Event:**
```
Title: "Mom's birthday gift"
Frequency: Yearly
Date: May 15
Reminder: 1 week before
```

## Task Notes

### What Are Notes?

Notes are detailed information attached to a task. Use them for context, instructions, or reference material.

**Examples:**
- Instructions for completing task
- Reference information
- Links to resources
- Contact information
- Important details

### Adding Notes

**During Task Creation:**
1. Scroll to "Notes" section
2. Tap the notes field
3. Type your notes
4. Format with rich text (bold, italic, lists)
5. Save task

**After Task Creation:**
1. Tap task to open
2. Tap "Edit"
3. Scroll to "Notes"
4. Add or edit notes
5. Save changes

### Note Features

**Rich Text Formatting:**
- **Bold** text
- *Italic* text
- ~~Strikethrough~~ text
- Lists (bullet and numbered)
- Headings

**Example Note:**
```
## Website Redesign Project

**Objectives:**
- Modernize design
- Improve mobile experience
- Increase conversion

**Resources:**
- Design mockups: [link]
- Brand guidelines: [link]
- Analytics data: [link]

**Steps:**
1. Review current design
2. Create mockups
3. Get approval
4. Implement changes
5. Test thoroughly
```

## Task Status

### Understanding Task Status

**Pending:**
- Task not yet started
- Default status for new tasks
- Shown in normal color

**In Progress:**
- Task currently being worked on
- Manually set by user
- Shown in blue

**Completed:**
- Task finished
- Marked by checking off
- Shown in gray with strikethrough
- Can be archived

**On Hold:**
- Task paused temporarily
- Waiting for something
- Shown in orange
- Can be resumed

### Changing Task Status

**Mark as In Progress:**
1. Tap task to open
2. Tap "Status" dropdown
3. Select "In Progress"
4. Save changes

**Mark as Completed:**
1. Tap task to open
2. Tap checkbox to complete
3. Task is marked done
4. Moved to completed section

**Mark as On Hold:**
1. Tap task to open
2. Tap "Status" dropdown
3. Select "On Hold"
4. Optionally add reason
5. Save changes

**Mark as Pending:**
1. Tap task to open
2. Tap "Status" dropdown
3. Select "Pending"
4. Save changes

## Best Practices

### Creating Effective Tasks

**1. Be Specific**
- ✅ "Buy milk, eggs, and bread"
- ❌ "Grocery shopping"

**2. Use Action Verbs**
- ✅ "Call dentist"
- ❌ "Dentist"

**3. Make Tasks Achievable**
- ✅ "Write first draft of report"
- ❌ "Complete entire project"

**4. Set Clear Due Dates**
- ✅ "June 30, 2026 at 5 PM"
- ❌ "Soon" or "Eventually"

**5. Break Down Complex Tasks**
- ✅ Use subtasks for large projects
- ❌ One huge task

### Managing Tasks Effectively

**1. Review Daily**
- Spend 5-10 minutes each morning
- Review today's tasks
- Adjust priorities
- Plan your day

**2. Prioritize Ruthlessly**
- Don't mark everything as critical
- Focus on 3-5 important tasks
- Say no to low-priority items
- Protect your time

**3. Complete Tasks**
- Finish tasks before starting new ones
- Check off completed tasks
- Feel sense of accomplishment
- Build momentum

**4. Review Weekly**
- Spend 30 minutes on Sunday
- Review completed tasks
- Plan next week
- Adjust categories and tags

**5. Archive Completed Tasks**
- Keep task list clean
- Archive old completed tasks
- Review archived tasks occasionally
- Celebrate progress

### Avoiding Common Mistakes

**Don't:**
- ❌ Create vague tasks
- ❌ Set unrealistic deadlines
- ❌ Overload with tasks
- ❌ Ignore low-priority tasks forever
- ❌ Create tasks you don't intend to do

**Do:**
- ✅ Create clear, specific tasks
- ✅ Set realistic deadlines
- ✅ Focus on quality over quantity
- ✅ Review and adjust regularly
- ✅ Only create tasks you'll actually do
